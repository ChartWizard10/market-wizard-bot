# CAP-40C Change Note

CAP-40C locks the candidate-cap boundary study before CAP-40 outcomes are reviewed for a capacity decision.

It adds one-earliest-observation-per-ticker/session sampling in America/New_York, explicit handling of current naive UTC autoscan timestamps, a committed 2026-08-20 through 2026-09-30 observation window with final review no earlier than 2026-10-08, predeclared sample/opportunity thresholds, Wilson uncertainty bounds, and a local report CLI.

A passing report can only mark a separately reviewed paid 30-vs-40 GPT-5.6 experiment as review-eligible. It does not change the production cap, add model calls, reconstruct shadow GPT-5.6 tiers, or grant tier/capital/routing authority.
